# 人物与场景截图硬性合同

## 清晰度硬门槛

人物脸部必须能看清眼睛、眉毛、鼻梁、嘴角和发型轮廓；动作截图必须能看清手部、身体边缘和动作方向；场景截图必须能看清地点边界、关键道具和人物相对位置。禁止失焦、拖影、运动模糊、压缩块、噪点遮脸、过曝、欠曝、黑帧和低清放大。

筛选时以 100% 原图查看为准，不以缩略图“看起来还行”为准。自动清晰度评分只能作为第一道拦截，任何人工看不清的图片都必须淘汰，即使它的评分勉强通过。

## 精确帧提取与 PTS 证据

- 联系表、低清代理帧和快速跳转画面只用于粗筛候选；不能直接进入人物图或场景图正式包。
- 候选帧必须保存源视频的真实 PTS ticks 与 time base。VFR 视频必须依据逐帧 PTS 选帧；禁止用 `r_frame_rate`、名义 FPS 或 `round(fps * seconds)` 从时间推算帧序号。不能证明某帧的真实 PTS 时，该候选不得进入交付。
- 正式提取必须从源视频起点按原始顺序解码，再按候选 PTS ticks 选择目标帧；不得使用输入侧 `-ss` 快速 seek 结果直接交付。可使用 `scripts/extract_verified_frame.py`，它通过 FFmpeg `select=eq(pts\,PTS_TICKS),showinfo` 顺序解码。
- 提取后必须核对 FFmpeg 回报的实际 PTS ticks 与候选 PTS ticks 完全一致，并用 source time base 换算秒数核对时码；不一致、找不到或出现多个匹配 PTS 时，删除临时候选并阻止该图进入正式包。
- 正式提取后重新生成源分辨率 PNG，并从该正式 PNG 生成较小预览缩略图供人工复核。人工必须检查人物身份、单人边界、动作完整度、场景信息和清晰度；预览图仅用于检查，不可替代正式 PNG。
- 提取证据至少保存：源 SHA256、源视频路径、提取方法、PTS ticks、time base、实际 PTS 秒数、核对后的源时码、正式图 SHA256/尺寸、预览缩略图路径/尺寸/SHA256、视觉审核状态。视觉审核状态在人工确认前只能为 `pending`。
- 对时码粗筛可以先用联系表定位，但最后候选必须映射回原视频的实际源 PTS；如果候选只能靠快速 seek 时间点表达、没有帧级 PTS 证据，则重新建立逐帧索引。

## 人物截图

### 新人物漏检门禁

- 每集分析结束都要把字幕姓名、台词称呼和视觉新脸候选写入 `人物角色注册表.json`，再开始选图；不能先写脚本、后补角色。
- 注册表中不存在的人物必须标为 `待核验`，记录集数、时间和证据；未完成确认前不允许套用已有角色图片。
- 只有通过“身份依据 + 单人物清晰图 + 文件名绑定”三项检查，人物才可从 `待核验` 变为 `已确认`。
- 全剧反查必须没有未登记人物；没有合格单人物图时只能记录排除原因，不能用多人图凑数。

每个发行包只输出该包实际出镜的人物图片。每个角色最多 5 张；能找到合格素材时，优先覆盖以下不同用途：

1. 全身或大半身：固定服装、身高感、身体比例和站位；
2. 半身或侧身：用于对话、转身和空间方向；
3. 代表动作：抬手、指人、拿物、推门、后退、坐下等具体动作；
4. 代表表情：愤怒、惊讶、委屈、心虚、冷笑、忍耐等具体神态；
5. 连续性参考：能看清发型、服装和脸部特征的稳定画面。

少于 5 张时少输出，禁止用多人图凑数。单张人物图不得出现其他人的脸、头发、手、肩、身体、倒影或屏幕人像。不得使用闭眼废帧、严重模糊、黑帧、遮挡主体、只剩身体局部的画面。不得把同一动作的相邻重复帧当成多张素材。

最终人物图必须从原视频正式时间点提取，保留原始截图分辨率和必要的完整身体范围。禁止用低清预览图替代，禁止放大，禁止固定裁掉左右 8%，禁止为了统一比例把脚、手、头或动作轨迹裁掉。

文件名固定为：

```text
人物_人物名_具体动作_具体神态_第XX集_00分XX.X秒.png
```

不得使用“主体动作参考”“人物素材”“角色1”“未确认角色”“[动作列表]”等泛化或程序残留命名。

## 场景截图

场景图的任务是让模型看清地点、空间关系、道具和人物相对位置。脸部特写、半身人物图、纯情绪图不能作为场景图。

每个实际场景目标最多输出 5 张不同用途的图；按视觉质量决定数量，允许少于 3 张或留空：

1. 空间建立图：能看出房间、门口、走廊、餐桌、接警桌等整体关系；
2. 关键道具图：能看出电视、手机、桌面、门、取样袋、文件等具体物件；
3. 冲突位置图：能看出人物站在哪里、谁靠近谁、谁挡住谁；
4. 动作后果图：能看出碎片、物品移位、门打开、桌面变化等结果；
5. 尾帧/反转图：能承接第二段或留下证据和悬念。

少于 3 张或为空时必须说明该场景确实没有更多合格画面，并在脚本写明“无合格场景图”及原因；不能用脸部特写、多人画面、人物手部/身体局部、带原片字幕或重复帧填充。每张场景图必须经过人工或视觉检查，确认不是人物脸部占据主体、不是纯黑或模糊画面、没有水印/Logo/播放器界面，并且能回答“地点在哪里、关键物在哪里、人物如何站位”。

文件名固定为：

```text
场景_具体地点_具体状态或道具_第XX集_00分XX.X秒.png
```

禁止使用“场景_原片空间与道具”“场景图1”“空间参考”“普通场景”等没有内容的名称。

## 脚本绑定

脚本每个镜头的“出镜人物”必须等于该镜头引用的人物图片集合；脚本每个镜头的场景图必须能支撑该镜头的地点、道具和站位。不能把女主角图片循环分配给只出现邻居的镜头，也不能把人物脸部图标成场景图。

## 交付前检查

生成联系图或逐包预览，逐张确认人物是否单人、动作是否完整、场景是否有空间信息、文件名是否具体。任何一张不满足规则都退回重选；不为凑数量降低标准。
