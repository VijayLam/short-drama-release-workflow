# 短剧二次发行输出合同

## 项目输出

正式目录位于源视频文件夹内：

```text
二次创作发行/
├── 生成清单.json
├── 01_引流款_第01集/
│   ├── 01_人物图片/
│   ├── 02_场景图片/
│   └── 03_脚本/Seedance_一键复制.md
├── 02_冲突款_第01集/
├── 03_矛盾款_第01集/
├── 04_激进款_第01集/
└── 05_爆款款_第01集/
```

每个“版本 × 集数”都是独立投喂包。包内不得引用其他包的图片；脚本引用的图片必须真实存在于同包的 `01_人物图片/` 或 `02_场景图片/`。

## 图片质量合同

- 人物图最多 5 张/角色，每张只能出现目标人物，不用多人图凑数。
- 最终人物图和场景图必须从原视频按原始时间点提取；预览缩略图不能替代正式图。
- 保留原始截图分辨率和完整动作范围，不强行放大、压缩或统一裁切。
- 人物文件名必须包含人物名、动作、神态、集数和时间；场景文件名必须包含场景、状态/道具、集数和时间。
- 图片可打开、不过暗、无黑帧、无播放器界面、无平台 Logo 或水印。

## 人物素材索引字段

`人物名`、`角色身份`、`动作/神态`、`集数`、`时间`、`源视频`、`输出文件`、`单人物检查`、`清晰度检查`、`状态`

## 场景素材索引字段

`场景名`、`地点/状态`、`关键道具`、`集数`、`时间`、`源视频`、`输出文件`、`人物干扰`、`字幕/Logo检查`、`状态`

## Seedance 一键复制文档

每个包的 Markdown 开头依次包含：

1. 项目标题、版本类型、总时长、画幅和现实主义风格；
2. 图片上传顺序；
3. 人物资产对应和场景资产对应；
4. 人物连续性规则；
5. 可直接复制的完整生成提示词。

完整提示词必须覆盖：`镜头编号`、`0.1秒起止时间`、`景别/机位`、`画面动作`、`人物站位与运动轨迹`、`手部动作`、`身体重心`、`眼神和面部表情`、`呼吸/停顿/抢话/打断`、`台词`、`旁白`、`字幕`、`BGM`、`音效`、`转场`、`尾帧`、`下一段承接`、`使用图片文件名`、`禁止项`。

每个镜头至少写出一个动作变化和一个神态变化，不能只写情绪标签。时间轴必须连续覆盖 `0.0—30.0秒`，明确 `0.0—15.0秒` 与 `15.0—30.0秒`。第一秒必须有冲突或强钩子。台词、口型和字幕必须一致；没有旁白时明确写“无旁白”。

## 速度与缓存合同

缓存键包含视频 SHA256、相对路径、Skill 版本、图像规则版本、脚本模板版本和分析模型版本。安全模式下每次先重新确认源视频 SHA256；缓存只用于索引、时间码、剧情事实和候选记录；正式图片仍从原视频提取。资源不足时降低并行度，不降低图片或脚本质量。

## 完成条件

- 所有可读视频有剧情记录和原片时间点；
- 版本包数量与生成清单一致；
- 每包目录、图片和 Markdown 齐全；
- 图片可读取、人物图单人物、每角色不超过 5 张；
- Markdown 中所有图片引用均存在；
- 时间轴无空档、无重叠、无占位词；
- 每个镜头包含动作、神态、台词、字幕和声音说明；
- 源视频哈希/大小/数量在处理前后未发生变化。
