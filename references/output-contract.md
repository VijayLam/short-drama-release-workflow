# 短剧二次发行输出合同

## 项目输出

正式目录位于源视频文件夹内：

```text
二次创作发行/
├── 生成清单.json
├── 01_引流款_第01集/
│   ├── 01_人物图片/
│   ├── 02_场景图片/
│   └── 03_脚本/Seedance_一键复制.md
├── 02_冲突款_第01集/
├── 03_矛盾款_第01集/
├── 04_激进款_第01集/
└── 05_爆款款_第01集/
```

每个“版本 × 集数”都是独立投喂包。包内不得引用其他包的图片；脚本引用的图片必须真实存在于同包的 `01_人物图片/` 或 `02_场景图片/`。

## 图片质量合同

- 清晰度是硬门槛：人脸五官、动作边缘、场景边界和关键道具必须在 100% 查看下清楚可辨；禁止失焦、拖影、压缩块、过曝、欠曝、黑帧和低清放大。
- 自动清晰度检查只能拦截明显问题，最终仍需逐张视觉检查；任何看不清的截图不得进入正式包。

- 人物图最多 5 张/角色，每张只能出现目标人物，不用多人图凑数。
- 最终人物图和场景图必须从原视频按原始时间点提取；预览缩略图不能替代正式图。
- 保留原始截图分辨率和完整动作范围，不强行放大、压缩或统一裁切。
- 人物文件名必须包含人物名、动作、神态、集数和时间；场景文件名必须包含场景、状态/道具、集数和时间。
- 图片可打开、不过暗、无黑帧、无播放器界面、无平台 Logo 或水印。

## 人物素材索引字段

`人物名`、`角色身份`、`动作/神态`、`集数`、`时间`、`源视频`、`输出文件`、`单人物检查`、`清晰度检查`、`状态`

## 场景素材索引字段

`场景名`、`地点/状态`、`关键道具`、`集数`、`时间`、`源视频`、`输出文件`、`人物干扰`、`字幕/Logo检查`、`状态`

## Seedance 一键复制文档

每个包的 Markdown 开头依次包含：

1. 项目标题、版本类型、总时长、画幅和现实主义风格；
2. 图片上传顺序；
3. 人物资产对应和场景资产对应；
4. 人物连续性规则；
5. 可直接复制的完整生成提示词。

完整提示词必须覆盖：`镜头编号`、`0.1秒起止时间`、`景别/机位`、`画面动作`、`人物站位与运动轨迹`、`手部动作`、`身体重心`、`眼神和面部表情`、`呼吸/停顿/抢话/打断`、`台词`、`旁白`、`字幕`、`BGM`、`音效`、`转场`、`尾帧`、`下一段承接`、`使用图片文件名`、`禁止项`。

每个镜头至少写出一个动作变化和一个神态变化，不能只写情绪标签。时间轴必须连续覆盖 `0.0—30.0秒`，明确 `0.0—15.0秒` 与 `15.0—30.0秒`。第一秒必须有冲突或强钩子。台词、口型和字幕必须一致；没有旁白时明确写“无旁白”。

## 速度与缓存合同

缓存键包含视频 SHA256、相对路径、Skill 版本、图像规则版本、脚本模板版本和分析模型版本。安全模式下每次先重新确认源视频 SHA256；缓存只用于索引、时间码、剧情事实和候选记录；正式图片仍从原视频提取。资源不足时降低并行度，不降低图片或脚本质量。

## 创意脚本合同

二次发行默认使用“素材借用 + 新冲突创作”模式。人物外形、服装、场景、空间关系和可复用道具来自源视频；冲突动机、人物立场、台词、信息揭示、转折、动作后果和结尾讨论点可以重新设计。只有用户明确要求还原原剧情时，才按原剧情复述。

每条 30 秒脚本必须有讨论命题、8—12 个可变微镜头、3 次立场或权力变化、2 次信息/情绪转折、1 个可验证证据、1 个动作或关系后果和 1 个争议性尾帧问题。台词必须是大众口语，避免专业腔、法律腔、新闻腔、总结腔和万能填充句。每句台词附说话对象、目的、潜台词、打断关系、权力变化和来源类型。

五种裂变必须改变开场事件、误判对象、证据时点、冲突升级、反转落点或结尾问题中的至少一项。只改标题和策略说明不算裂变。

## 图片与连续性硬合同

人物图必须按角色和用途筛选，每个角色最多 5 张，单张只出现该人物，最终帧从原视频正式提取，禁止预览帧、放大、固定裁切、多人图、重复帧和泛化命名。场景图每个实际场景目标 3—5 张，必须分别承担空间建立、关键道具、冲突位置、动作后果或尾帧承接；脸部特写不能作为场景图。

人物文件名必须符合 `人物_人物名_具体动作_具体神态_第XX集_00分XX.X秒.png`；场景文件名必须符合 `场景_具体地点_具体状态或道具_第XX集_00分XX.X秒.png`。

每条 30 秒脚本必须明确分为 `0.0—15.0 秒` 和 `15.0—30.0 秒`。第一段尾帧必须写出人物位置、面向、手部、重心、道具、光线和声音；第二段开场必须从同一尾帧继续，写出动作延续，不得重新摆位或概括跳过。

`Seedance_一键复制.md` 只放用户需要复制给模型的内容，并用 `【一键复制开始】`、`【一键复制结束】` 标记复制范围。质量日志、缓存信息、内部字段和长篇解释不得混入复制区。

## 完成条件

- 所有可读视频有剧情记录和原片时间点；
- 版本包数量与生成清单一致；
- 每包目录、图片和 Markdown 齐全；
- 图片可读取、人物图单人物、每角色不超过 5 张；
- Markdown 中所有图片引用均存在；
- 时间轴无空档、无重叠、无占位词；
- 每个镜头包含动作、神态、台词、字幕和声音说明；
- 源视频哈希/大小/数量在处理前后未发生变化。
