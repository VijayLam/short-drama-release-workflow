# 短剧二次发行输出合同

## 项目输出

正式目录位于源视频文件夹内：

```text
二次创作发行/
├── 生成清单.json
├── 01_矛盾款_第01集/
│   ├── 01_人物图片/
│   ├── 02_场景图片/
│   └── 03_脚本/Seedance_一键复制.md
```

默认每集只交付一个独立投喂包。上例仅展示某集最终选中“矛盾款”的命名；实际类型须先根据本集剧情评估五种类型，排除不适配项后从剩余适配项中随机选择，不能按集号轮换。用户明确要求同一集多个版本时，才为该集增加包。内部清单记录每集所选类型、简短剧情依据和随机选择结果，不混入一键复制正文。包内不得引用其他包的图片；脚本引用的图片必须真实存在于同包的 `01_人物图片/` 或 `02_场景图片/`。

## 原片人物完整性门禁

项目级 `00_人物素材库/` 收录原片全部可辨认出镜角色；单集包的 `01_人物图片/` 只复制该脚本实际使用的角色。逐集人物盘点独立于脚本选角。

每集注册表必须记录完整场景 ID、逐场景审核人/时间/联系表证据、候选人物 ID/时间码/身份归属、`source_visible_characters` 和未归属候选。审核场景 ID 必须覆盖全部预期场景，联系表文件必须存在于源目录缓存中。逐集出镜角色集合与人物表的视觉出现集数必须双向一致；台词提及单独记录。

每个原片出镜角色在素材库必须有1—5张已通过单人、身份、清晰度审核的图片，分别覆盖正脸/表情、全身/大半身、动作/神态；三个基础覆盖槽必须绑定不同文件且文件内容不能重复。服装/场景变化存在时补充，不足项必须附核验原因。缺角色、缺图、未归属候选或场景审核漏项均阻断正式发行。

## 人物素材索引字段

`人物名`、`角色身份`、`动作/神态`、`集数`、`时间`、`源视频`、`输出文件`、`单人物检查`、`清晰度检查`、`状态`

项目级人物素材库覆盖所有原片出镜角色，每人最多5张。单人审核必须排除其他人的脸、头发、手、肩、身体、倒影或屏幕人像；至少区分脸部/表情、全身/大半身和动作/神态截图。姓名无法确认时使用角色称呼并标注“姓名未确认”，但不能因此漏截。

## 场景素材索引字段

`场景名`、`地点/状态`、`关键道具`、`集数`、`时间`、`源视频`、`输出文件`、`人物干扰`、`字幕/Logo检查`、`状态`

## Seedance 一键复制文档

每个包必须有 `03_脚本/Seedance_一键复制.md`，开头依次包含：

1. 项目标题、版本类型、总时长、画幅和现实主义风格；
2. 图片上传顺序；
3. 人物资产对应和场景资产对应；
4. 人物连续性规则；
5. 可直接复制的完整生成提示词。

完整提示词必须覆盖：

`镜头编号`、`0.1秒起止时间`、`景别/机位`、`画面动作`、`人物站位与运动轨迹`、`手部动作`、`身体重心`、`眼神和面部表情`、`呼吸/停顿/抢话/打断`、`台词`、`旁白`、`字幕`、`BGM`、`音效`、`转场`、`尾帧`、`下一段承接`、`使用图片文件名`、`禁止项`

默认时间轴连续覆盖 `0.0—30.0秒`，并在15.0秒分段。生成清单应记录 `script_contract`：`total_duration_seconds`、`segment_boundary_seconds`、`min_shots`、`max_shots`；用户指定其他时长或分段时，按清单合同连续覆盖并承接。第一秒必须有冲突或强钩子。台词、口型和字幕必须一致；没有旁白时明确写“无旁白”。

## 部分交付验收

每个发行包独立验收并归属到集数。某集的人物待核验、素材缺失或脚本不合格只阻塞该集；其他通过包可以交付。结果必须明确列出通过包、阻塞包及原因，不得把部分交付标成全剧完成。

验收工具采用状态 `partial_passed` 时，只要至少有一个通过包且不存在全局清单错误，就返回成功退出码0，即使还有阻塞包；没有通过包或存在全局清单错误时返回2。调用方必须同时读取状态和包列表，不能仅凭退出码宣称全量通过。

## 内部核对表（可选）

需要排期或来源核对时可以额外生成 Excel，工作表建议为：`逐集剧情`、`关键节点`、`人物素材索引`、`场景素材索引`、`分镜脚本`。Excel 不能替代包内 Markdown，也不能要求用户回看 Excel 才能生成。

## 完成条件

- 所有可读视频有剧情记录和原片时间点；
- 版本包数量与生成清单一致；
- 每包目录、图片和 Markdown 齐全；
- 逐集原片人物清单完整且覆盖所有场景；每个出镜角色在项目级素材库有已审核人物图；单集包人物图与脚本角色对应，每人不超过5张；
- Markdown 中所有图片引用均存在；
- 时间轴无空档、无重叠、无占位词；
- 源视频哈希/大小/数量在处理前后未发生变化。
